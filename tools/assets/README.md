# Dog asset preparation

The bundled dog is derived from the user's supplied USDZ, preserved unchanged in `assets-source/dog-source.usdz`. Conversion runs at development time; the Android app loads the bundled GLB offline.

From the repository root, with Blender 5.2 installed:

```powershell
./tools/assets/prepare-dog.ps1 -Source ./assets-source/dog-source.usdz
```

Use `-Blender`, `-Profile`, `-Output`, and `-WorkDir` for other explicit paths. Add `-Render` for preview PNGs. The CLI extracts the USDZ inside the work directory so Blender can resolve both JPEG textures without relying on platform temporary directories. It preserves source skin weights and embeds the base color and normal maps. Blender runs in a separate background process with factory settings and does not modify the user's open scene.

The JSON profile explicitly maps four anatomical leg chains, torso, head and tail. The source uses Z up and -Y forward. The exporter produces metres, Y up and +Z forward, about 0.45m high with feet at y=0. Both Idle and Walk are grounded standing poses; Walk has no forward root motion. A 1.2s four-beat cycle has a reference movement speed of 0.15783m/s. Unsupported axes, absent armature/weights/textures or missing mapped bones fail clearly. Another rig requires an inspected anatomical profile, not just matching a file name.

`validate_dog.py` independently imports the generated GLB and confirms embedded textures, exact clip names, 54 skin joints and nonstatic deformation of actual mesh vertices. It writes `glb-validation.json`; conversion writes `conversion-report.json` with source/output SHA-256 and parameters. These are integration inspections, not mocked animation tests.

The original model is seated and its autogenerated weights create visible creases and pinching around the unfolded hindquarters. This procedural walk is a working AR prototype, not a polished locomotion asset. A production walk needs manual weight cleanup and animation review. Actual Android AR rendering and ground movement require device verification.
